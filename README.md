The proposed two-step temporal decomposition methodology for precipitation forecasting typically leverages publicly accessible synoptic meteorological station data from Iran obtained through the Iranian Meteorological Organization (IRIMO) or international platforms such as NOAA's Global Surface Summary of the Day (GSOD). Monthly and annual precipitation records spanning multiple decades across diverse climatic regions—representing arid, semi-arid, and humid zones—form the foundation of the analysis. The decomposition process generally employs MATLAB with specialized time series toolboxes, implementing algorithms such as Empirical Mode Decomposition (EMD) to disaggregate precipitation series into high-frequency and low-frequency components. The separate modeling approach, using machine learning frameworks or hybrid architectures within MATLAB, processes each frequency component independently, with code available through this repository. The training datasets are commonly divided into calibration (typically 70-80% of available data) and validation periods to assess model performance metrics including precision, accuracy, and error measures (RMSE, MAE), ensuring robust evaluation across the three distinct climate classifications studied.​
